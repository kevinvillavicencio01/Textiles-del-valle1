# Textiles del Valle · Simulador de decisiones

Mini Reto II · Hilos de incertidumbre · Equipo financiero

Página web que simula 3,000 trimestres (Monte Carlo) para decidir cuánto producir y si conviene el contrato escolar a 90 días. Basada en `Textiles_del_Valle_Excel_v5_entrega.xlsx`.

## Uso
Abre `index.html` en el navegador. No necesita instalación.
